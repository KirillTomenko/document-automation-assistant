# work_request/2.0 — поддерживаемые структуры

Согласовано владельцем 20.10.2026. Расширение DEMO_CONTRACT.md и VARIANT_B.md;
исторический контракт v1 сохраняется для чтения и регрессии. Бизнес-поля,
нормализация, human-in-the-loop и ограничения операций прежние.

Формат выбирает парсер. Роль определяют разрешённые подписи, разделы и заголовки;
один документ может иметь несколько ролей. Отдельный файл на роль не требуется.
Ограничения: 1–10 файлов, 10 MiB на файл, 30 MiB суммарно и прежние лимиты парсеров.

Подписанные поля: прежние подписи VARIANT_B во всех форматах; отдельная строка
«подпись: значение» либо простая пара соседних ячеек. Общее «Наименование» — только
в явно обозначенной карточке заказчика. Раздел описания ограничен следующим
заголовком/подписанным полем/таблицей; Excel-описание — одна подписанная ячейка.

Позиции: одна однозначная таблица на документ. Заголовки и единицы — VARIANT_B.
Word: прямоугольная таблица без объединений/вложений. Excel: прежние ограничения.
PDF: текстовые строки, разделитель `|` или табуляция, однозначные заголовки,
одна строка на позицию, без переноса ячеек/таблицы через страницу. Визуальные
колонки без явного разделителя, сканы и сложная вёрстка не поддерживаются.

Позиции разных документов сохраняются отдельно, без суммирования. Идентичность
строки: document_id, таблица/страница, строка. Повторный код в комплекте — ambiguous.
Возможные одинаковые строки без кода требуют проверки и не сливаются.
Побайтовые дубли файлов извлекаются один раз, но отмечаются duplicate_document.
Одинаковые скалярные значения — found со всеми источниками; разные — conflict.
Неполнота, неоднозначность и неподдерживаемые структуры — needs_review;
критическая ошибка чтения/адаптера — failed и запрет обоих DOCX.

Новые результаты содержат contract_version=2.0; отсутствие поля означает 1.0.
Каноническая сериализация v1 не добавляет новых полей. Старые snapshots, audit,
digest и fingerprints не переписываются. SQLite не требует разрушительной миграции.
Проверка provenance подтверждает происхождение, а не истинность исходных сведений.

Это конечный набор структур; матрица 27 форматов не означает универсального
понимания произвольных PDF/DOCX/XLSX. Реальные платные вызовы для проверки запрещены.
