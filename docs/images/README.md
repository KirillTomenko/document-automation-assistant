# Изображения синтетического offline demo

- [Рабочая заявка V](work-request-v.png): целиком одна страница, черновик с
  частичными позициями и местами для ручного заполнения.
- [Отчёт V](verification-report-v.png): первая из пяти страниц, состояния и проблемы.
- [Источники в отчёте V](verification-sources-v.png): страница 3, фрагменты и координаты.

Это изображения DOCX приложения, а не дизайнерские макеты или ответы реальной LLM.
Источники — только отслеживаемые синтетические файлы [demo/V](../../demo/V).
Организация «Демо Офис», адрес example.com и учебные работы выдуманы.

Использован сохранённый рендер LibreOffice через render_docx.py; исходные DOCX
повторно прошли verify_document / verify_verification_report текущего генератора.
Публикуемые страницы осмотрены визуально: таблицы и текст читаемы, обрезки нет.
Идентификатор на изображении относится только к синтетической обработке.
Рендер не гарантирует идентичного переноса строк в Microsoft Word.

Для повторения содержимого запустите offline demo, выберите V, скачайте оба DOCX.
run_id и техническое время нового запуска будут другими. Для получения PNG нужен
отдельный рендерер Word/LibreOffice; он не требуется для запуска приложения и тестов.
Полные DOCX, JSON результатов и журналы остаются локальными и не включены в репозиторий.
