# Состояние подготовки публичной версии 2.0.0

Окончательное публичное дерево подготовлено из принятого 2.0.0rc1 на основе
действующей публичной истории Git, отдельно от рабочего проекта и publication-snapshot.
**NO-GO для публикации:** исходные pypdf/Streamlit advisories устранены,
но остаётся несовместимость исправленной Pillow 13.0.0 с ограничением Streamlit <13.
Текущий [аудит зависимостей и повторная приёмка](DEPENDENCY_SECURITY_REVIEW.md).
Commit, push, тег, GitHub Release и изменение GitHub Pages не выполнялись.

Результаты независимых проверок, ограничения и вердикт:
[PUBLICATION_DIFF_REVIEW.md](../PUBLICATION_DIFF_REVIEW.md).
Текущий состав и SHA-256: [PUBLICATION_MANIFEST.json](PUBLICATION_MANIFEST.json).
Исторические результаты этапа 10C: [отчёт кандидата](RELEASE_CANDIDATE_REPORT.md)
и [его manifest](RELEASE_MANIFEST.json); они описывают 2.0.0rc1.

После отдельного решения владельца: устранить проблемы зависимостей, повторить
приёмку и получить GO. Затем согласовать окончательный diff, сохранить
публичные пути видео/Pages/иллюстраций, выполнить GitHub CI на разрешённой публикации.
MIT LICENSE уже присутствует. Новые ролик, обложка, схема и страница пока только
[предложены](DEMO_V2_PROPOSAL.md), существующие материалы сохранены.

Публичный исходный код не означает разрешение размещать локальный API/UI в интернете.
