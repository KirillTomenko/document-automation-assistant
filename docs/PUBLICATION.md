## Действия перед созданием репозитория

1. Ещё раз проверить содержимое снимка и актуальность его локальных коммитов.
2. Создать пустой публичный репозиторий `document-automation-assistant` без
   автоматически добавляемых README, LICENSE или `.gitignore`.
3. После отдельного разрешения добавить удалённый адрес и отправить ветку `main`.
4. Проверить отображение README, схемы Mermaid и изображений, а также дождаться
   успешного GitHub Actions CI.
5. Записать демонстрацию продолжительностью 60–90 секунд и при необходимости
   проверить открытие документов в целевом браузере и Word.

Проект остаётся локальным однопользовательским MVP без авторизации. Не открывайте
его API или UI в интернет без дополнительной защиты. Публичные примеры должны
содержать только синтетические данные.
