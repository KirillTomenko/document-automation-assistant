# Экранная демонстрация за 60–90 секунд

Цель: показать путь от трёх документов к двум проверяемым результатам и участие
человека при пропусках. Весь показ — offline, без платных запросов.

## Подготовка

1. Запустите demo по [README](../README.md). Python: UI 8501/API 8000;
   Docker: UI 18501/API 18000. Убедитесь, что интерфейс показывает demo-режим.
2. Используйте только `demo/A` и `demo/B`. Закройте личные вкладки, терминалы
   с окружением и несинтетические документы. Отключите уведомления.
3. Откройте три файла A и приготовьте Word/LibreOffice для скачанных документов.
   Выполните репетицию скачивания обоих файлов. Не показывайте ключи или логи.
4. Записывайте окно приложения и документов при читаемом масштабе. Ожидание загрузки
   можно сократить монтажом, не скрывая предупреждения и статусы.

## План записи

| Время | Экран и действие | Короткая подпись |
|---|---|---|
| 0–10 с | Три синтетических файла A: PDF, DOCX, XLSX | «Данные о заказчике и работах приходят в разных форматах» |
| 10–25 с | Выбрать A и нажать «Обработать», показать статус | «Offline demo: без ключа и платных запросов» |
| 25–40 с | Скачать и открыть рабочую заявку | «Рабочая заявка для проверки и редактирования» |
| 40–58 с | Скачать отчёт, показать источники и координаты | «Отдельный отчёт объясняет происхождение значений» |
| 58–75 с | Обработать B, показать пропущенную дату и черновик | «Отсутствующие сведения не выдумываются — требуется человек» |
| 75–85 с | Вернуться к двум операциям скачивания | «Один результат обработки — два документа» |

Финальная подпись: «LLM предлагает кандидатов; приложение проверяет источники
и разрешения. В этом видео показан offline-режим».

## Что не заявлять

Не называйте offline показ живым вызовом модели. Реальный ProxyAPI A прошёл;
реальный V был отклонён до 3A. Прямой OpenAI API не проверялся. Provenance
показывает происхождение, а не доказывает истинность исходных сведений.
Не обещайте измеренную экономию времени или точность на любых документах.

Видео пока не записано. [Публичные изображения](images/README.md) используют
синтетический V и показывают маркировку needs_review и первую страницу отчёта.
