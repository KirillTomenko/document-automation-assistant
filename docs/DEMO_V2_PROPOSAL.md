# Предложения для публичных материалов 2.0

Это сценарий для согласования, не запись нового видео. Действующие видео, обложки,
SVG и docs/index.html остаются побайтово прежними. Корневой URL Pages,
docs/video/document-automation-assistant-demo.mp4 и существующие имена изображений
сохраняются после будущего релиза; новый ролик предложено добавить под новым именем.

## Схема README

Вместо привязки «карточка=PDF, описание=Word, позиции=Excel» показать три смысловые
группы, у каждой — PDF / DOCX / XLSX. Под ними: «Только поддерживаемые структуры».
Далее: чтение → проверка значений и источников → needs_review / проверка человеком
→ рабочая заявка + отчёт проверки. SQLite/audit показать небольшим нижним блоком.
Подпись: «27 сочетаний проверенных структур; без OCR и произвольной вёрстки».
Не рисовать обещание универсальной обработки и гарантированной экономии.

## Обложка

Предлагаемый текст: «Документы → 2 Word-результата»; подзаголовок:
«Одинаковые и смешанные форматы · источники · проверка».
Метка «Offline demo · синтетические данные». Визуально — три Word-иконки и
смешанный PDF/Word/Excel набор, два выходных листа. Без финансовых обещаний.
Пока сохранить действующую обложку и ссылку README.

## Основной ролик: ориентир 110–130 секунд

| Время | Действие | Что показать |
|---|---|---|
| 0–10 | Назвать ручную задачу | Сбор сведений и подготовка двух Word-документов; offline, синтетика |
| 10–35 | Загрузить customer.docx, description.docx, items.docx | Три файла одинакового формата, completed, поля и позиции |
| 35–55 | Новый смешанный комплект: customer.xlsx, description.pdf, items.docx | Роли независимы от формата; проверенные структуры, не произвольные файлы |
| 55–75 | Открыть источник значения | Имя файла, исходный фрагмент, лист/ячейка либо абзац/таблица/строка |
| 75–100 | Загрузить C с конфликтом | needs_review, два источника, нет автоматического выбора победителя |
| 100–120 | Скачать оба DOCX | Черновик рабочей заявки и отдельный отчёт проверки с источниками |
| 120–130 | Завершить | Сотрудник проверяет результат; ссылка на offline demo и ограничения |

Если переключения займут больше времени, не ускорять чтение источников:
сократить вводную или разделить демонстрацию. Принятие можно кратко показать
после проверки обоих DOCX; не выдавать нажатие за исправление конфликта.

Отдельный ролик 60–90 секунд: mock usage, неизвестная стоимость, средняя только
при достаточных данных; backup → verify → restore и прежние DOCX после рестарта.
На всём блоке расходов — заметная подпись «Симуляция; условные тарифы; не списания».
Не выполнять реальных платных запросов ради записи.
