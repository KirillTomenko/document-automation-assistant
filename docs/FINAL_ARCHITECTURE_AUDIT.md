# Архитектурные замечания перед релизом 2.0

Это публичная сводка подтверждённых исправлений; внутренний журнал разработки
и диагностические материалы в кандидат не включены. Полные результаты именно
кандидата: [RELEASE_CANDIDATE_REPORT.md](RELEASE_CANDIDATE_REPORT.md).

| Замечание | Исправление | Проверка и статус |
|---|---|---|
| H01: конфликт подписанного поля после таблицы XLSX мог пропускаться | Явная граница таблицы возвращает подписанные поля в скалярный проход | Регрессии до/после таблицы, одинаковые/разные значения, offline/mock, координаты и оба DOCX; закрыто |
| H02: неполная таблица XLSX могла скрываться корректными позициями другого файла | Потенциальная неполная или неоднозначная таблица даёт unsupported_content с источниками; строки не выдумываются | Неполные/дублированные заголовки, другой источник, вспомогательные таблицы, needs_review и оба DOCX; закрыто для определённых структур |
| H03: non-root не мог создать parent lock при data=/data | UID/GID 1000:1000, writable /var/lib/daa, data=/var/lib/daa/data, два общих mounts | Фактический Docker Desktop Linux/WSL2: named volumes, Windows bind, Compose, SQLite, shared lock, HTTP, DOCX, restart и синтетический прежний layout; закрыто в проверенной среде |
| M01: публичное описание отставало от функций | README и актуальные инструкции обновлены, исторические проверки отмечены | Существующие видео, обложки, схема и Pages сохранены; обновления только предложены |

Новые исправления извлечения применяются к новым обработкам. Старые snapshots,
audit и fingerprints не переписываются; потенциально затронутые исторические
результаты должен пересмотреть оператор. Новый запуск использует новый ключ.

Матрица 27 проверяет конечные структуры; она не означает поддержку любых файлов
этих расширений. Реальная LLM на v2 не проверена. Provenance доказывает происхождение,
а не истинность сведений. completed, needs_review и принятие — разные признаки.

Локальные ограничения: один backend, нет авторизации/OCR/шифрования; пределы загрузки
1–10 файлов, 10 MiB на файл, 30 MiB на комплект. Расходы — оценка LLM API, не полная
себестоимость; unknown не равен нулю. SQLite и файлы не имеют общей атомарной транзакции;
восстановление и backup требуют штатных условий и доступного общего lock.
Данные другого проекта и рабочие volumes для проверки не использовались.
Проверка не сертифицирует произвольные ACL, ОС, аппаратные отказы или безопасность
против администратора с доступом к хранилищу.
